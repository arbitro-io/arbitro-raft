Verified end-to-end: election converges; a stream created on one node replicates to the other two with an identical id (real committed Raft entry); **leader kill → re-election** (survivors keep serving, new stream commits + replicates, pre-kill stream survives); and **node restart → rejoin → catch-up** (a restarted node recovers its own persisted state AND catches up on entries missed while down, then receives new writes). First end-to-end proof outside the in-process harness — it validated the happy path AND surfaced three real gaps the in-process tests could not (the channel transport makes "reconnect" a no-op): **L13 restarted-node-never-rejoins — found AND fixed** (dead-connection eviction), L11 single-node self-election (open), L12 election-window error mapping (open). Drivers: `arbitro-server` + `arbitroctl`.
